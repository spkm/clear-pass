# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities through public issues, discussions or pull requests.

Instead, [report the vulnerability privately](https://github.com/spkm/clear-pass/security/advisories/new) through GitHub. Only you and the maintainer can see the report, so the issue can be fixed before it is made public.

It helps to include:

- what is affected (the package version, and the class or endpoint)
- the steps to reproduce the issue, or a proof of concept
- the impact, as you understand it
